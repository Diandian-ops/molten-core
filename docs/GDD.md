# MOLTEN CORE（熔核守卫）— 游戏设计文档 v0.1

## 一、世界观 / 历史背景

### 时代背景
千年前，人类文明在地心深处发现了「熔核」（Molten Core）——一种由星辰坠落地底、经亿万年高压淬炼而成的能量奇点。熔核散发的地火之力驱动了「熔炼纪元」的文明大爆发：城邦以熔核为心脏，管道如血脉般延伸，锻造出改写历史的兵器与机械。

但熔核的力量并非没有代价。过度汲取熔核之力，会在地脉深处唤醒被称为「灼灭者」（The Scorched）的古老存在——它们本是熔核最初的守护者，因文明的贪婪掠夺而堕化为纯粹的破坏本能，如今潮水般涌向每一座熔核之城，意图夺回或摧毁这份力量。

### 阵营
- **熔核祭司团（玩家阵营）**：世代守护熔核的技师与战士后裔，掌握「熔铸术」——将熔核能量注入守卫塔与器械的技艺。信条是「宁毁己身，不熄核火」。
- **灼灭者（敌方）**：由堕化的守护构装体、熔岩生物、以及被侵蚀的古代机兵组成的敌人序列，随着关卡推进逐渐从「失控的兽群」演变为「有意志的军团」。
- **深渊回声（Boss / 后期反派）**：传说中第一代熔核守护者的残骸意识，是最终章的最终威胁，代表「力量本身并无善恶，滥用才招致毁灭」的主题。

### 故事主线（章节式，对应关卡分组）
1. **序章·熔炉苏醒**：主角作为新晋祭司，在自己家乡的熔核站首次抵御灼灭者袭击，了解熔核的基本运作。
2. **第一章·地脉裂痕**：地脉出现异常裂痕，灼灭者数量激增，玩家需要建立更强的防线并追溯裂痕成因。
3. **第二章·锻炉遗迹**：深入古代锻炉遗迹，发现熔核滥用导致的历史悲剧遗迹，剧情揭示灼灭者堕化的真相。
4. **终章·深渊回声**：抵达地心最深处，直面深渊回声，玩家必须选择「封印熔核」或「与之共鸣」，对应两种结局。

### 核心主题
科技与自然的失衡、力量的代价、守护与贪婪的对立。故事以碎片化的「熔核日志」「守护者残响」等文本收集品在关卡中呈现，不打断玩法节奏。

## 二、游戏类型与核心玩法

**类型**：2D 塔防 + 闯关（Tower Defense / Wave Defense），俯视或半俯视视角。

### 核心循环
1. 每关地图中央有一个「熔核」（核心），拥有能量值（等价于生命值）。
2. 灼灭者从地图边缘的多个「裂痕点」分波次涌向熔核。
3. 玩家在预设的可布防格子上放置/升级「守卫塔」，消耗「熔能晶币」。
4. 熔能晶币通过击杀敌人、熔核自身被动产出、或关卡内采集点获得。
5. 熔核能量归零则关卡失败；抵挡完所有波次则关卡胜利，获得星级评价（基于熔核剩余能量、通关时间、晶币结余等）。

### 守卫塔类型（初版占位，后续可扩展）
- **熔火塔**：单体持续灼烧伤害，基础输出。
- **震波塔**：范围击退+减速，控制人流。
- **熔晶塔**：不直接攻击，提升周围守卫塔的攻速/伤害（呼应"熔铸术"设定）。

### 敌人类型（初版占位）
- **灼奴**：数量多、脆皮、快速，试探玩家布防。
- **熔壳兵**：高护甲，慢速，需要集中火力。
- **裂痕使者**：会直接冲向熔核附带自爆，需优先处理。

### 关卡结构
关卡数据以资源文件（`.tres`）描述：波次数量、每波敌人构成与生成延迟、地图裂痕点坐标、初始晶币、星级评价阈值。这样策划可以在编辑器中直接调整数值，不需要改代码。

## 三、技术方案

- **引擎**：Godot 4.7（GDScript），原生支持导出 Windows / macOS / Linux / iOS / Android（APK/AAB）/ HTML5，一套项目多端打包。
- **架构**：
  - Autoload 单例：`GameManager`（全局状态、关卡进度、晶币）、`AudioManager`（音效/音乐）。
  - 场景分层：`Boot` → `MainMenu` → `LevelSelect` → `Level`（关卡内再分 `Core`、`Enemy`、`Tower`、`SpawnPoint`、`HUD`）→ `ResultScreen`。
  - 关卡数据驱动：`Resource`（`LevelData.gd` + `WaveData.gd`）定义波次和地图参数，关卡场景通用逻辑读取数据生成。
- **美术资源**：初版使用几何占位图形（`ColorRect` / 简单 `.svg` 占位），后续替换为像素或扁平化插画风格美术资源。
